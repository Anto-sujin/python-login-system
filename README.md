# \# Python Login \& Registration System

# 

# A simple user authentication system built using Python and SQLite.

# 

# \## Features

# 

# \- User registration

# \- Email validation

# \- Password validation

# \- Duplicate email checking

# \- SQLite database storage

# \- Parameterized SQL queries

# 

# \## Technologies

# 

# \- Python

# \- SQLite

# \- Regular Expressions

# \- Git \& GitHub

# 

# \## Project Structure

# 

# login.py - Main registration/login program

# 

# text.py - Database email validation functions

# 

# user.db - Local SQLite database (not included in GitHub)

# 

# \## Security

# 

# Parameterized SQL queries are used to help prevent SQL injection.
